= allure whoami

Команда `allure whoami` выводит информацию о текущем пользователе, вошедшем в Allure Service.

== Синтаксис

[source,bash]
----
$ allure whoami [options]
----

== Опции

`--config, -c <путь>`::
Путь к файлу конфигурации Allure.

`--cwd <путь>`::
Рабочая директория для запуска команды. По умолчанию используется текущая рабочая директория.

== Примеры

.Вывести информацию о текущем пользователе, используя конфигурацию по умолчанию:
[source,bash]
----
$ allure whoami
----

.Вывести информацию о текущем пользователе, используя кастомный файл конфигурации:
[source,bash]
----
$ allure whoami --config custom-config.js
----
