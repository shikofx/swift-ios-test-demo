= Введение в Jekyll и GitHub Pages

Добро пожаловать в серию уроков по использованию Jekyll для создания статических сайтов и их публикации на GitHub Pages!

== Что такое Jekyll?

*Jekyll* — это простой, статический генератор сайтов, написанный на Ruby. Он берет ваш контент, написанный в Markdown (или других форматах), и шаблоны (Liquid), а затем генерирует полностью статический HTML-сайт, готовый к развертыванию. Jekyll не использует базы данных или серверные скрипты, что делает его быстрым, безопасным и простым в обслуживании.

== Что такое GitHub Pages?

*GitHub Pages* — это сервис хостинга статических сайтов, предоставляемый GitHub. Он позволяет вам размещать веб-сайты прямо из репозиториев GitHub. GitHub Pages идеально подходит для хостинга персональных, организационных или проектных сайтов. Он имеет встроенную поддержку Jekyll, что делает процесс публикации очень удобным.

== Почему Jekyll + GitHub Pages?

* *Простота:* Легко начать работу, особенно если вы знакомы с Markdown.
* *Бесплатно:* GitHub Pages предоставляет бесплатный хостинг.
* *Версионный контроль:* Весь ваш сайт хранится в Git-репозитории, что обеспечивает полный контроль версий.
* *Безопасность и скорость:* Статические сайты не подвержены многим уязвимостям динамических сайтов и очень быстро загружаются.
* *Автоматизация:* С помощью GitHub Actions можно автоматизировать сборку и развертывание сайта при каждом изменении.
