== 3. Пайпы и функции

`jq` позволяет комбинировать фильтры с помощью пайпа (`|`) и использовать встроенные функции для более сложной обработки.

=== Пайп `|`

Пайп в `jq` работает так же, как в shell: он передает результат одного фильтра на вход другому.

*Пример: получить имена всех пользователей из массива*
[source,bash]
----
echo '[{"name": "Alice"}, {"name": "Bob"}]' | jq '.[] | .name'
# Вывод:
# "Alice"
# "Bob"
----

=== Функция `select()`

`select()` позволяет фильтровать элементы, которые удовлетворяют условию.

*Пример: найти всех пользователей старше 30*
[source,bash]
----
echo '[{"name": "Alice", "age": 25}, {"name": "Bob", "age": 35}]' | jq '.[] | select(.age > 30)'
# Вывод: { "name": "Bob", "age": 35 }
----

В нашем CI мы используем `select(.severity=="Error")` для подсчета количества ошибок.

=== Другие полезные функции

*   `length`: возвращает длину массива или строки.
*   `keys`: возвращает массив ключей объекта.
*   `unique`: удаляет дубликаты из массива.
