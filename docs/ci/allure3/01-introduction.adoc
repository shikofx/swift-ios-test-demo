== Что такое Allure Framework?

**Allure Framework** — это гибкий и легковесный инструмент для создания тестовых отчетов. Его главная задача — не просто показать результат прогона тестов (passed/failed), а предоставить максимум информации для анализа: шаги теста, вложения (скриншоты, логи), тайминги, историю запусков и многое другое.

Отчеты Allure строятся на основе JSON-файлов, которые генерируются специальными адаптерами для различных тестовых фреймворков.

== Ключевые преимущества Allure 3

Allure 3 — это значительное обновление фреймворка, которое принесло множество улучшений:

*   **Новый пользовательский интерфейс:** UI был полностью переработан. Он стал современнее, быстрее и информативнее.
*   **Улучшенная производительность:** Генерация отчетов и работа с ними стали значительно быстрее, что особенно заметно на больших проектах.
*   **Плагины:** Появилась мощная система плагинов, которая позволяет кастомизировать отчет, добавлять новые виджеты и интегрироваться с внешними системами (например, Jira, Jenkins).
*   **Улучшенная история запусков (Trends):** Графики трендов стали более наглядными и стабильными.
*   **Архитектура на Node.js:** Allure 3 построен на Node.js и распространяется как npm-пакет, что упрощает его установку и использование в современных CI/CD пайплайнах.

== Обзор структуры отчета

Стандартный отчет Allure 3 включает в себя несколько ключевых разделов:

*   **Overview:** Главная страница с дашбордами, виджетами и общей статистикой по последнему запуску.
*   **Categories:** Автоматическая классификация упавших тестов по типам дефектов (например, "Product Defects", "Test Defects").
*   **Suites:** Группировка тестов по тестовым наборам (классам).
*   **Graphs:** Визуализация статистики в виде графиков (по статусам, длительности, severity).
*   **Timeline:** Временная шкала, которая показывает, как тесты выполнялись параллельно.
