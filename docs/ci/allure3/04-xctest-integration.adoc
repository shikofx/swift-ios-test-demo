== Особенности интеграции

В отличие от многих других тестовых фреймворков (JUnit, TestNG, Pytest), **XCTest не имеет нативной поддержки Allure**. Это означает, что нет официального адаптера, который можно было бы подключить к коду тестов для добавления аннотаций `@Step`, `@Feature` и т.д.

Вся интеграция происходит постфактум, после завершения тестового прогона.

== Процесс получения Allure-отчета

Процесс генерации отчета для Swift-проекта состоит из трех основных шагов:

.   **Запуск тестов:**
    С помощью `xcodebuild` мы запускаем тесты и получаем на выходе артефакт — бандл `.xcresult`. Этот бандл содержит всю информацию о прогоне: какие тесты запускались, их статусы, логи, скриншоты и другие вложения.

.   **Генерация отчета:**
    Команда `allure awesome` напрямую парсит `.xcresult` бандл и создает на его основе полноценный HTML-отчет.

Схематично этот процесс выглядит так:
`xcodebuild test` -> `Test.xcresult` -> `allure awesome` -> `allure-report`
