= Интеграция в CI
:sectnums:
:source-highlighter: highlight.js

Автоматизация генерации отчетов — ключевая задача при внедрении Allure. Процесс интеграции зависит от конкретной CI/CD системы, но общие шаги остаются похожими:

1.  **Запуск тестов:** Настроить шаг для выполнения тестов и сохранения артефактов (например, `.xcresult`).
2.  **Генерация отчета:** Добавить шаг, который скачивает артефакты и генерирует HTML-отчет с помощью Allure CLI.
3.  **Публикация:** Настроить развертывание сгенерированного отчета на статический хостинг (GitHub Pages, GitLab Pages, etc.).
4.  **Сохранение истории:** Реализовать механизм сохранения папки `history` между запусками для построения графиков трендов.
