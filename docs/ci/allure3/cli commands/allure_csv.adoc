= allure csv

Команда `allure csv` генерирует CSV-отчет из указанной директории с результатами Allure.

== Синтаксис

[source,bash]
----
$ allure csv [options] <путь_к_директории_с_результатами>
----

== Опции

`--config, -c <путь>`::
Путь к файлу конфигурации Allure.

`--cwd <путь>`::
Рабочая директория для запуска команды. По умолчанию используется текущая рабочая директория.

`--output, -o <путь>`::
Имя выходного файла. Также принимаются абсолютные пути.

`--disable-headers`::
Укажите, чтобы отключить заголовки в CSV-файле.

`--separator <разделитель>`::
Разделитель столбцов в CSV-файле.

`--known-issues <путь>`::
Путь к файлу известных проблем. Обновляет файл и помещает упавшие тесты в карантин, если указано.

== Примеры

.Сгенерировать CSV-отчет из директории `./allure-results`:
[source,bash]
----
$ allure csv ./allure-results
----

.Сгенерировать CSV-отчет из `./allure-results` в файл `custom-report.csv`:
[source,bash]
----
$ allure csv ./allure-results --output custom-report.csv
----
