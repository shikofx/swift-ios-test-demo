= allure log

Команда `allure log` выводит результаты Allure из указанной директории прямо в консоль. Это удобный способ быстро просмотреть статусы тестов без генерации полного HTML-отчета.

== Синтаксис

[source,bash]
----
$ allure log [options] <путь_к_директории_с_результатами>
----

== Опции

`--config, -c <путь>`::
Путь к файлу конфигурации Allure.

`--cwd <путь>`::
Рабочая директория для запуска команды. По умолчанию используется текущая рабочая директория.

`--group-by <тип>`::
Группировать тесты по типу (например, `none`, `suite`, `feature`, `package` и т.д.).

`--all-steps`::
Показать все шаги. По умолчанию отображаются только упавшие шаги.

`--with-trace`::
Вывести стектрейс для упавших тестов.

== Примеры

.Вывести результаты из директории `./allure-results`:
[source,bash]
----
$ allure log ./allure-results
----

.Вывести результаты со всеми шагами и стектрейсами из директории `./allure-results`:
[source,bash]
----
$ allure log ./allure-results --all-steps --with-trace
----
