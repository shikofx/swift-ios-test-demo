= allure logout

Команда `allure logout` выполняет выход из Allure Service, используя данные из файла конфигурации Allure.

== Синтаксис

[source,bash]
----
$ allure logout [options]
----

== Опции

`--config, -c <путь>`::
Путь к файлу конфигурации Allure.

`--cwd <путь>`::
Рабочая директория для запуска команды. По умолчанию используется текущая рабочая директория.

== Примеры

.Выполнить выход из Allure Service, используя конфигурацию по умолчанию:
[source,bash]
----
$ allure logout
----

.Выполнить выход из Allure Service, используя кастомный файл конфигурации:
[source,bash]
----
$ allure logout --config custom-config.js
----
