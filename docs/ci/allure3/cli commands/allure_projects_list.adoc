= allure projects list

Команда `allure projects list` выводит список всех доступных проектов для текущего пользователя и позволяет выбрать один для получения информации о конфигурации.

== Синтаксис

[source,bash]
----
$ allure projects list [options]
----

== Опции

`--config, -c <путь>`::
Путь к файлу конфигурации Allure.

`--cwd <путь>`::
Рабочая директория для запуска команды. По умолчанию используется текущая рабочая директория.

== Примеры

.Вывести список всех доступных проектов:
[source,bash]
----
$ allure projects list
----
