= Переменные окружения в GitHub Actions
:source-highlighter: highlight.js
toc::[]
== Цели урока

* Понять, какие переменные окружения доступны в среде выполнения GitHub Actions.
* Научиться использовать эти переменные для создания более гибких и динамичных пайплайнов.

---

== Теория

GitHub Actions автоматически предоставляет набор переменных окружения для каждого шага в рабочем процессе. Эти переменные содержат информацию о событии, которое запустило workflow, о среде выполнения, о коде и многом другом.

Ниже приведены все переменные из вашего лога запуска, сгруппированные по категориям.

=== Переменные среды выполнения (`RUNNER_*`)

Эти переменные описывают виртуальную машину (runner), на которой выполняется ваша задача.

[cols="1,2,2"]
|===
| Переменная | Пример значения | Описание

| `RUNNER_OS`
| `macOS`
| Операционная система, на которой работает runner.

| `RUNNER_ARCH`
| `ARM64`
| Архитектура процессора runner'а.

| `ImageOS`
| `macos15`
| Конкретный образ ОС, используемый для runner'а.
| `RUNNER_ENVIRONMENT`
| `github-hosted`
| Среда, в которой работает runner (например, `github-hosted` или `self-hosted`).
| `RUNNER_NAME`
| `GitHub Actions 1000001788`
| Имя runner'а.
| `RUNNER_TEMP`
| `/Users/runner/work/_temp`
| Путь к временной директории на runner'е.
| `RUNNER_TOOL_CACHE`
| `/Users/runner/hostedtoolcache`
| Путь к кэшу инструментов на runner'е.
| `RUNNER_TRACKING_ID`
| `github_5d843992-1e33-40e4-a6a6-a035efdcda45`
| ID отслеживания runner'а.
|===
