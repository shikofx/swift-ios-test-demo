= 2. Основная конфигурация Jekyll

Центральным файлом для настройки вашего Jekyll-сайта является `_config.yml`. Он находится в корневой директории вашего сайта (в нашем случае, это `.site/`). Этот файл использует формат YAML и позволяет задавать глобальные переменные, настройки сборки и плагины.

== Основные параметры в `_config.yml`

Вот некоторые из наиболее часто используемых параметров:

[source,yaml]
----
title: Мой Заголовок Сайта # Главный заголовок вашего сайта
description: Краткое описание моего сайта # Описание, используемое для SEO и в темах
baseurl: "/my-project" # Если ваш сайт размещен в поддиректории (например, github.com/user/my-project)
url: "https://user.github.io" # Полный URL вашего сайта

theme: jekyll-theme-cayman # Используемая тема Jekyll (об этом подробнее в следующем уроке)

plugins:
  - jekyll-feed # Пример плагина для RSS-ленты
  - jekyll-sitemap # Пример плагина для генерации sitemap.xml
  - ./_plugins/my_custom_plugin.rb # Пример подключения локального плагина

markdown: kramdown # Парсер Markdown (kramdown - стандартный и рекомендуемый)
kramdown:
  input: GFM # GitHub Flavored Markdown
  hard_wrap: false

exclude: # Файлы и папки, которые Jekyll должен игнорировать при сборке
  - Gemfile
  - Gemfile.lock
  - README.md
  - node_modules/
----

== Важные моменты:
* *`baseurl`*: Используйте его, если ваш сайт размещен не в корне домена (например, на GitHub Pages для репозитория `username/repo-name`, `baseurl` будет `/repo-name`).
* *`url`*: Полный URL вашего сайта. Важен для генерации абсолютных ссылок.
* *`theme`*: Определяет, какую тему Jekyll будет использовать.
* *`plugins`*: Список плагинов, которые Jekyll должен загрузить. Локальные плагины указываются с путем относительно корня сайта.
* *`exclude`*: Список файлов и папок, которые не должны быть скопированы в итоговый статический сайт.

После изменения `_config.yml` всегда перезапускайте сервер Jekyll (или запускайте сборку в CI), чтобы изменения вступили в силу.
