== 6. Файлы данных (папка `_data`)

Jekyll имеет мощную функцию для работы с внешними данными — специальную папку `_data`. Это предпочтительный способ отделить данные от кода и шаблонов.

=== Как это работает?

1.  **Создайте папку `_data`** в корне вашего Jekyll-сайта (например, `.site/_data`).
2.  **Поместите в нее файлы данных**. Jekyll поддерживает форматы `.yml`, `.yaml`, `.json`, `.csv` и `.tsv`.
3.  **Используйте данные в шаблонах**. Jekyll автоматически прочитает эти файлы и сделает их доступными через глобальный объект `site.data`.

=== Пример

Предположим, у вас есть файл `_data/swiftlint.json` с таким содержимым:

[source,json]
----
[
  { "file": "FileA.swift", "line": 10, "severity": "Warning" },
  { "file": "FileB.swift", "line": 25, "severity": "Error" }
]
----

Jekyll сделает эти данные доступными как `site.data.swiftlint`. Теперь вы можете легко вывести их в виде таблицы на любой странице:

[source,liquid]
----
{% for violation in site.data.swiftlint %}
  - Файл: {{ violation.file }}, Строка: {{ violation.line }}
{% endfor %}
----

Именно этот подход мы используем в нашем CI для отображения отчетов SwiftLint и SwiftFormat. Он позволяет избежать сложных преобразований данных и делает код чище и понятнее.
