== 1. Введение в jq

`jq` — это легковесный и очень мощный процессор JSON для командной строки. Его можно представить как `sed` для JSON-данных: вы можете использовать его для нарезки, фильтрации, маппинга и трансформации структурированных данных с той же легкостью, с какой `awk`, `sed` и `grep` позволяют работать с текстом.

=== Зачем использовать `jq`?

*   **Извлечение данных**: Легко получить значение конкретного ключа из сложного JSON.
*   **Фильтрация**: Выбрать только те объекты, которые соответствуют определенным условиям.
*   **Трансформация**: Изменить структуру JSON, добавить или удалить поля.
*   **Интеграция в скрипты**: Идеально подходит для использования в shell-скриптах и CI/CD пайплайнах для автоматизации задач.
