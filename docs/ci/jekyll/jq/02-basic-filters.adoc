== 2. Базовые фильтры

Основа `jq` — это фильтры. Фильтр принимает JSON на вход и производит JSON на выходе.

=== Фильтр идентичности: `.`

Самый простой фильтр — это точка (`.`), которая возвращает входные данные без изменений.

[source,bash]
----
echo '{"user": "gemini", "id": 1}' | jq '.'
# Вывод: { "user": "gemini", "id": 1 }
----

=== Доступ к полям объекта: `.key`

Для доступа к значению по ключу используется синтаксис `.key`.

[source,bash]
----
echo '{"user": "gemini", "id": 1}' | jq '.user'
# Вывод: "gemini"
----

=== Итератор по массиву: `.[]`

Если на входе массив, фильтр `.[]` вернет каждый элемент этого массива на отдельной строке.

[source,bash]
----
echo '[{"id": 1}, {"id": 2}]' | jq '.[]'
# Вывод:
# { "id": 1 }
# { "id": 2 }
----

Именно этот фильтр используется в нашем CI для перебора всех нарушений из отчета SwiftLint.
