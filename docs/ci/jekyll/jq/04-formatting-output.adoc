== 4. Форматирование вывода

`jq` предоставляет специальные фильтры для контроля над форматом вывода.

=== Фильтр `@json`

Этот фильтр берет любое JSON-значение (объект, массив, строку) и преобразует его в компактное строковое представление.

[source,bash]
----
echo '{"user": "gemini", "id": 1}' | jq '@json'
# Вывод: "{\"user\":\"gemini\",\"id\":1}"
----

Именно этот фильтр мы используем в нашем CI для подготовки данных к вставке в `Front Matter` Jekyll-страницы. Он гарантирует, что каждый объект будет представлен как одна валидная JSON-строка, которую затем можно будет передать в YAML-список.
