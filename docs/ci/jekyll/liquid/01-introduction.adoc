== 1. Введение в синтаксис Liquid

Liquid — это язык шаблонов с открытым исходным кодом, созданный Shopify. Он используется в Jekyll для загрузки динамического контента на статические страницы. Liquid позволяет вам вставлять данные, выполнять логические операции и форматировать вывод прямо в ваших HTML-шаблонах или Markdown-файлах.

=== Основные концепции

Liquid оперирует тремя основными типами конструкций:

1.  *Объекты (Objects):* Выводят данные на страницу. Они заключены в двойные фигурные скобки: `{{ object }}`.
2.  *Теги (Tags):* Создают логику и контролируют поток шаблона. Они заключены в фигурные ско скобки и знаки процента: `{% tag %}`.
3.  *Фильтры (Filters):* Модифицируют вывод объектов. Они используются внутри объектов и отделяются вертикальной чертой: `{{ object | filter }}`.

=== Пример

Вот простой пример, демонстрирующий все три концепции:

[source,liquid]
----
Привет, {{ site.title }}!
{% assign name = "Мир" %}
{% if name == "Мир" %}
  Это мой первый Liquid-шаблон.
{% endif %}
Сегодня: {{ "now" | date: "%Y-%m-%d" }}
----
