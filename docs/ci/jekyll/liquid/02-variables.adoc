== 2. Переменные и Объекты

В Liquid *объекты* используются для вывода данных на страницу. Они могут быть простыми переменными, значениями из конфигурации сайта, данными из файлов или результатами других операций.

=== Вывод объектов

Чтобы вывести значение объекта, используйте двойные фигурные скобки:

[source,liquid]
----
{{ site.title }}
{{ page.title }}
{{ post.title }}
----

Здесь:
*   `site` — глобальный объект, содержащий данные из `_config.yml`.
*   `page` — объект, содержащий данные текущей страницы (из фронтматтера).
*   `post` — объект, содержащий данные текущего поста (если это пост).

=== Присвоение переменных

Вы можете создавать свои собственные переменные с помощью тега `assign`:

[source,liquid]
----
{% assign my_variable = "Привет, Liquid!" %}
{{ my_variable }}

{% assign product_price = 19.99 %}
{% assign total_items = 5 %}
{% assign total_cost = product_price | times: total_items %}
Общая стоимость: {{ total_cost }}
----

Переменные, созданные с `assign`, доступны только в том шаблоне, где они были определены, и в любых включенных файлах (`_includes`).
