== 3. Теги управления потоком

Теги в Liquid используются для создания логики и управления потоком шаблона. Они не выводят ничего на страницу напрямую, но влияют на то, какой контент будет отображен.

=== Условные теги (`if`, `elsif`, `else`, `unless`)

Эти теги позволяют отображать контент в зависимости от выполнения условий.

[source,liquid]
----
{% assign user_logged_in = true %}
{% if user_logged_in %}
  Добро пожаловать, пользователь!
{% else %}
  Пожалуйста, войдите.
{% endif %}

{% assign product_count = 0 %}
{% unless product_count > 0 %}
  Корзина пуста.
{% endunless %}
----

=== Циклы (`for`)

Тег `for` позволяет итерироваться по коллекциям (массивам, хешам).

[source,liquid]
----
{% assign products = "Яблоко,Банан,Апельсин" | split: "," %}
{% for product in products %}
  - {{ product }}
{% endfor %}
----

Вы также можете использовать `for` с объектами, такими как `site.posts` или `site.pages`.
