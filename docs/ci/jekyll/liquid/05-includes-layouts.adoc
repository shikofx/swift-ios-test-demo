== 5. Включения и Макеты

Включения (`_includes`) и макеты (`_layouts`) — это мощные функции Jekyll, которые используют Liquid для повторного использования кода и поддержания единообразного дизайна на всем сайте.

=== Включения (`_includes`)

Включения — это фрагменты кода Liquid, HTML или Markdown, которые можно повторно использовать в любом месте вашего сайта. Они хранятся в папке `_includes/`.

*Пример использования:*

Предположим, у вас есть файл `_includes/footer.html`:

[source,html]
----
<footer>
  <p>&copy; {{ "now" | date: "%Y" }} {{ site.title }}</p>
</footer>
----

Вы можете включить его в любой шаблон или страницу:

[source,liquid]
----
{% include footer.html %}
----

Вы также можете передавать параметры во включения:

[source,liquid]
----
{% include header.html title="Мой Кастомный Заголовок" %}
----

=== Макеты (`_layouts`)

Макеты — это шаблоны, которые определяют общую структуру страницы. Они хранятся в папке `_layouts/`. Каждая страница или пост может указать, какой макет использовать, в своем фронтматтере.

*Пример макета (`_layouts/default.html`):*

[source,html]
----
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>{{ page.title }} - {{ site.title }}</title>
</head>
<body>
    <header>
        <h1>{{ site.title }}</h1>
    </header>
    <main>
        {{ content }}
    </main>
    {% include footer.html %}
</body>
</html>
----

*Использование макета в странице (`mypage.adoc`):*

[source,asciidoc]
----
---
layout: default
title: Моя Страница
---
= Заголовок Моей Страницы

Это содержимое моей страницы, которое будет вставлено в `{{ content }}` макета `default`.
----

Макеты могут быть вложенными, то есть один макет может использовать другой макет. Это позволяет создавать сложную иерархию шаблонов.
