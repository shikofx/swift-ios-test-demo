= 4. Кастомные стили и переопределение шаблонов

Хотя темы Jekyll предоставляют готовый дизайн, часто возникает необходимость внести небольшие изменения или полностью переопределить некоторые части. Jekyll предоставляет гибкие механизмы для этого.

== Добавление кастомных стилей

Лучший способ добавить свои стили, не затрагивая исходные файлы темы, — это использовать Sass/SCSS.

1. *Создайте файл `style.scss`:* В директории `assets/css/` вашего сайта (т.е. `.site/assets/css/`) создайте файл `style.scss`.

2. *Импортируйте стили темы:* В начале вашего `style.scss` импортируйте стили вашей темы. Это позволит вам использовать переменные и миксины темы, а также переопределять ее правила.

[source,scss]
----
// .site/assets/css/style.scss
@import "{{ site.theme }}";

/* Ваши кастомные стили начинаются здесь */
body {
  font-family: 'Arial', sans-serif;
  color: #333;
}

header {
  background-color: #f0f0f0;
  padding: 20px;
  text-align: center;
}
----

Строка `@import "{{ site.theme }}";` указывает Jekyll импортировать основной файл стилей активной темы.

3. *Добавьте свои правила:* После строки `@import` вы можете добавлять любые свои CSS-правила. Они будут применены после стилей темы, что позволит им переопределять существующие правила.

== Переопределение шаблонов темы

Темы Jekyll состоят из файлов в папках `_layouts`, `_includes`, `_sass` и `assets`. Вы можете переопределить любой из этих файлов, создав файл с таким же именем в соответствующей папке в корневой директории вашего сайта.

Например, если вы хотите изменить макет по умолчанию (`default.html`) вашей темы:

1. *Найдите файл темы:* Найдите `default.html` в структуре вашей темы (обычно это `_layouts/default.html` внутри гема темы).
2. *Создайте свой файл:* Создайте файл `.site/_layouts/default.html`.
3. *Скопируйте и измените:* Скопируйте содержимое оригинального `default.html` в ваш новый файл и внесите необходимые изменения. Jekyll будет использовать вашу версию вместо версии из темы.

Это очень мощный механизм, позволяющий полностью контролировать внешний вид и структуру вашего сайта, сохраняя при этом преимущества использования темы.
