= Написание нового поста
:author: Cotes Chung
:revdate: 2019-08-08
:last-update-date: 2025-09-08
:toc:
:lang: ru

Это руководство расскажет вам, как написать пост для шаблона Chirpy. Его стоит прочитать, даже если вы уже использовали Jekyll, так как многие функции требуют установки определенных переменных.

== Именование и путь

Создайте новый файл с именем `YYYY-MM-DD-TITLE.EXTENSION` и поместите его в каталог `_posts` в корневом каталоге. Обратите внимание, что `EXTENSION` должен быть `md` или `markdown`. Если вы хотите сэкономить время на создании файлов, рассмотрите возможность использования плагина `Jekyll-Compose`.

== Front Matter

В основном, вам нужно заполнить Front Matter в верхней части поста следующим образом:

[source,yaml]
----
---
title: TITLE
date: YYYY-MM-DD HH:MM:SS +/-TTTT
categories: [TOP_CATEGORY, SUB_CATEGORY]
tags: [TAG]     # Имена тегов всегда должны быть в нижнем регистре
---
----

Макет для постов по умолчанию установлен как `post`, поэтому нет необходимости добавлять переменную `layout` в блок Front Matter.

=== Временная зона даты

Чтобы точно записать дату публикации поста, вы должны не только настроить `timezone` в `_config.yml`, но и указать временную зону поста в переменной `date` его блока Front Matter. Формат: `+/-TTTT`, например, `+0800`.

=== Категории и теги

Категории каждого поста могут содержать до двух элементов, а количество тегов может быть от нуля до бесконечности. Например:

[source,yaml]
----
---
categories: [Животные, Насекомые]
tags: [пчела]
---
----

=== Информация об авторе

Информацию об авторе поста обычно не нужно заполнять в Front Matter, она по умолчанию будет получена из переменных `social.name` и первой записи `social.links` в файле конфигурации. Но вы также можете переопределить ее следующим образом:

Добавьте информацию об авторе в `_data/authors.yml` (если у вас нет этого файла, создайте его).

[source,yaml]
----
<author_id>:
  name: <полное_имя>
  twitter: <twitter_автора>
  url: <домашняя_страница_автора>
----

А затем используйте `author` для указания одной записи или `authors` для нескольких:

[source,yaml]
----
---
author: <author_id>                     # для одной записи
# или
authors: [<author1_id>, <author2_id>]   # для нескольких записей
---
----

Преимущество чтения информации об авторе из файла `_data/authors.yml` в том, что на странице будет метатег `twitter:creator`, что обогащает Twitter Cards и полезно для SEO.

=== Описание поста

По умолчанию первые слова поста используются для отображения в списке постов на главной странице, в разделе "Читайте также" и в XML-ленте RSS. Если вы не хотите отображать автоматически сгенерированное описание, вы можете настроить его с помощью поля `description` в Front Matter:

[source,yaml]
----
---
description: Краткое содержание поста.
---
----

Кроме того, текст описания будет отображаться под заголовком поста на его странице.

=== Оглавление (TOC)

По умолчанию оглавление (TOC) отображается на правой панели поста. Если вы хотите отключить его глобально, перейдите в `_config.yml` и установите значение переменной `toc` на `false`. Если вы хотите отключить TOC для конкретного поста, добавьте следующее в его Front Matter:

[source,yaml]
----
---
toc: false
---
----

=== Комментарии

Глобальная настройка комментариев определяется опцией `comments.provider` в файле `_config.yml`. Как только система комментариев будет выбрана, комментарии будут включены для всех постов.

Если вы хотите закрыть комментарии для конкретного поста, добавьте следующее в его Front Matter:

[source,yaml]
----
---
comments: false
---
----

== Медиа-ресурсы

В Chirpy мы называем изображения, аудио и видео медиа-ресурсами.

=== Префикс URL

Иногда нам приходится определять одинаковые префиксы URL для нескольких ресурсов в посте. Вы можете избежать этой рутинной задачи, установив два параметра.

Если вы используете CDN для хостинга медиафайлов, вы можете указать `cdn` в `_config.yml`. URL-адреса медиа-ресурсов для аватара сайта и постов будут иметь префикс домена CDN.

Чтобы указать префикс пути к ресурсам для текущего поста/страницы, установите `media_subpath` в Front Matter:

[source,yaml]
----
---
media_subpath: /path/to/media/
---
----

Опции `site.cdn` и `page.media_subpath` можно использовать по отдельности или в комбинации для гибкого составления конечного URL ресурса: `[site.cdn/][page.media_subpath/]file.ext`

=== Изображения

==== Подпись

Добавьте курсив в следующей строке после изображения, и он станет подписью, которая появится под изображением:

----
image::/path/to/image.jpg[Описание изображения]

_Подпись к изображению_
----

==== Размер

Чтобы предотвратить смещение макета страницы при загрузке изображения, мы должны установить ширину и высоту для каждого изображения. Для SVG необходимо указать хотя бы ширину.

`image::/assets/img/sample/mockup.png[Вид на десктопе, width="700", height="400"]`

==== Позиция

По умолчанию изображение центрируется, но вы можете указать позицию, используя один из атрибутов: `align=left` или `float=left`/`float=right`.

*Выравнивание по левому краю:*
`image::/assets/img/sample/mockup.png[Вид на десктопе, align=left]`

*Обтекание слева:*
`image::/assets/img/sample/mockup.png[Вид на десктопе, float=left]`

*Обтекание справа:*
`image::/assets/img/sample/mockup.png[Вид на десктопе, float=right]`

==== Темный/Светлый режим

Вы можете сделать так, чтобы изображения соответствовали предпочтениям темы в темном/светлом режиме. Для этого нужно подготовить два изображения и использовать атрибут `dark-light`.

`image::/path/to/image.png[Атрибуты, dark-light]`

==== Тень

Скриншоты окон программ можно отображать с эффектом тени:

`image::/assets/img/sample/mockup.png[Вид на десктопе, shadow]`

==== Изображение для предпросмотра

Если вы хотите добавить изображение вверху поста, предоставьте изображение с разрешением 1200 x 630. Укажите его в Front Matter:

[source,yaml]
----
---
image:
  path: /path/to/image
  alt: альтернативный текст изображения
---
----

== Встраивание из социальных сетей

Вы можете встраивать видео/аудио из социальных сетей с помощью следующего синтаксиса:

[source,liquid]
----
{% raw %}
{% include embed/{Platform}.html id='{ID}' %}
{% endraw %}
----

Где `Platform` — это имя платформы в нижнем регистре, а `ID` — это идентификатор видео. Поддерживаемые платформы: `youtube`, `twitch`, `bilibili`, `spotify`.

== Видео и аудио файлы

Если вы хотите встроить видео или аудио файл напрямую, используйте следующий синтаксис:

[source,liquid]
----
{% raw %}
{% include embed/video.html src='{URL}' %}
{% include embed/audio.html src='{URL}' %}
{% endraw %}
----

== Закрепленные посты

Вы можете закрепить один или несколько постов вверху главной страницы. Включите это с помощью:

[source,yaml]
----
---
pin: true
---
----

== Математика

Мы используем MathJax для отображения математики. Чтобы включить эту функцию, добавьте в Front Matter:

[source,yaml]
----
---
math: true
---
----

== Mermaid

Mermaid — отличный инструмент для создания диаграмм. Чтобы включить его, добавьте в Front Matter:

[source,yaml]
----
---
mermaid: true
---
----

Затем вы можете использовать его, как и другие языки разметки, окружив код диаграммы `[mermaid]` и `....`.
