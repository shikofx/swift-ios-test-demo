= Отчет за 30.10.2025: Работа над дашбордом (4.5 часа)

Сегодня мы успешно завершили первый этап плана по созданию дашборда с историей билдов, сфокусировавшись на визуальной составляющей и компоновке макета.

== Основные достижения:

1.  **Интеграция навигационных блоков:**
    *   В основные шаблоны (`swift-dashboard.html` и `swift-allure-main-page.html`) были добавлены два блока для будущих списков: "Builds" и "Branches".
    *   Эти блоки размещены в левой панели (`<header>`) под основным меню навигации.

2.  **Стилизация и дизайн:**
    *   Блоки были стилизованы с использованием `<fieldset>` и `<legend>` для создания эффекта рамки с "наезжающим" на нее заголовком.
    *   Реализована прокрутка (`overflow-y: auto`) внутри блоков, что позволяет отображать длинные списки.
    *   Проработан дизайн элементов списка билдов: теперь они включают иконку статуса (успех/провал/отмена), номер билда и дату. Иконки имеют фиксированную ширину для ровного выравнивания текста.

3.  **Глобальная перекомпоновка макета:**
    *   Футер был перемещен из левой панели и теперь является статичным, полноширинным элементом внизу страницы.
    *   Основная структура страницы была полностью переработана с использованием CSS Flexbox. Это позволило "прижать" футер к низу, а левой и правой панелям — динамически занимать все оставшееся пространство по высоте, что устранило нежелательную прокрутку всей страницы.
    *   Исправлена ошибка, из-за которой правая контентная область (`<section>`) "залезала" под левую панель.

4.  **Коррекция `iframe`:**
    *   Отключена логика автоматического изменения высоты для Allure-отчета, чтобы `iframe` имел фиксированную высоту и собственную прокрутку, не скрывая футер.

== Итог:

На данный момент мы имеем полностью готовую визуальную основу для дашборда. Шаблоны содержат все необходимые стилизованные блоки, которые пока наполнены статичными (фейковыми) данными.

**Следующий шаг по плану:** Вернуть в шаблоны условную логику (`{% if page.is_main_branch %}`) и научить CI-пайплайн передавать в них соответствующий флаг для отображения одного или двух блоков.
