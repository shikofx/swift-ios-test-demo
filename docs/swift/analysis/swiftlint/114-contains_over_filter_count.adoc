= Rule: Contains over Filter Count
:source-highlighter: highlight.js

Предпочитает `contains` вместо `.filter(...).count > 0`.

*Identifier*: `contains_over_filter_count`

== Non-compliant

[source,swift]
----
let result = myArray.filter { $0.isAwesome }.count > 0
----

== Compliant

[source,swift]
----
let result = myArray.contains { $0.isAwesome }
----
