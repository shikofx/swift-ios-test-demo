= Rule: Contains over Filter is Empty
:source-highlighter: highlight.js

Предпочитает `!contains` вместо `.filter(...).isEmpty`.

*Identifier*: `contains_over_filter_is_empty`

== Non-compliant

[source,swift]
----
let result = myArray.filter { $0.isAwesome }.isEmpty
----

== Compliant

[source,swift]
----
let result = !myArray.contains { $0.isAwesome }
----
