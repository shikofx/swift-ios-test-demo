= Rule: Empty Parentheses with Trailing Closure
:source-highlighter: highlight.js

При использовании `trailing closure` пустые круглые скобки в вызове функции следует опускать.

*Identifier*: `empty_parentheses_with_trailing_closure`

== Non-compliant

[source,swift]
----
foo() { ... }
----

== Compliant

[source,swift]
----
foo { ... }
----
