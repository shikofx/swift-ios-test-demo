= Rule: File Length
:source-highlighter: highlight.js

Ограничивает количество строк в файле. Длинные файлы сложно читать и поддерживать.

*Identifier*: `file_length`

== Non-compliant (если в файле > 400 строк по умолчанию)

[source,swift]
----
// 500 строк кода...
----

*Решение*: Разделить большой файл на несколько более мелких и сфокусированных.

== Конфигурация

Можно изменить пороговые значения для предупреждения и ошибки в `.swiftlint.yml`.
