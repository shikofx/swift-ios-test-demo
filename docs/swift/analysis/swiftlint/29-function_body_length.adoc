= Rule: Function Body Length
:source-highlighter: highlight.js

Ограничивает количество строк в теле функции. Длинные функции сложно читать, тестировать и поддерживать.

*Identifier*: `function_body_length`

== Non-compliant (если в функции > 40 строк по умолчанию)

[source,swift]
----
func myBigFunction() {
    // 50 строк кода...
}
----

*Решение*: Разбить большую функцию на несколько более мелких, каждая из которых выполняет одну задачу.

== Конфигурация

Можно изменить пороговые значения в `.swiftlint.yml`.
