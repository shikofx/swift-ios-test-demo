= Rule: Function Name Whitespace
:source-highlighter: highlight.js

Проверяет, что между именем функции и открывающей скобкой нет пробелов.

*Identifier*: `function_name_whitespace`

== Non-compliant

[source,swift]
----
func myFunc () {}
----

== Compliant

[source,swift]
----
func myFunc() {}
----
