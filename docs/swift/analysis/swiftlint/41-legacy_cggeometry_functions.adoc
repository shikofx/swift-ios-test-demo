= Rule: Legacy CGGeometry Functions
:source-highlighter: highlight.js

Предпочитает использование современных методов и свойств `CoreGraphics` вместо устаревших C-функций.

*Identifier*: `legacy_cggeometry_functions`

== Non-compliant

[source,swift]
----
let frame = CGRectMake(0, 0, 100, 100)
----

== Compliant

[source,swift]
----
let frame = CGRect(x: 0, y: 0, width: 100, height: 100)
----
