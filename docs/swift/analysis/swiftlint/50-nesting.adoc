= Rule: Nesting
:source-highlighter: highlight.js

Ограничивает глубину вложенности типов и функций. Глубокая вложенность усложняет код.

*Identifier*: `nesting`

== Non-compliant (если глубина > 1 для типов и > 5 для функций)

[source,swift]
----
class A {
    class B { // Нарушение: вложенность типов > 1
        func c() {
            func d() { ... }
        }
    }
}
----

*Решение*: Вынести вложенные типы и функции на верхний уровень.

== Конфигурация

Можно изменить пороговые значения в `.swiftlint.yml`.
