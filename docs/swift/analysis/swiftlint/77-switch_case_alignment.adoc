= Rule: Switch and Case Statement Alignment
:source-highlighter: highlight.js

Проверяет, что `case` и `default` в `switch` имеют тот же отступ, что и сам `switch`.

*Identifier*: `switch_case_alignment`

== Non-compliant

[source,swift]
----
switch foo {
    case .bar: break
    default: break
}
----

== Compliant

[source,swift]
----
switch foo {
case .bar: break
default: break
}
----
