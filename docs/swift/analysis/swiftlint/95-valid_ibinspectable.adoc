= Rule: Valid IBInspectable
:source-highlighter: highlight.js

Проверяет, что свойства, помеченные как `@IBInspectable`, имеют поддерживаемый тип.

*Identifier*: `valid_ibinspectable`

== Non-compliant

[source,swift]
----
@IBInspectable var foo: String?
----

== Compliant

[source,swift]
----
@IBInspectable var foo: String = ""
----
