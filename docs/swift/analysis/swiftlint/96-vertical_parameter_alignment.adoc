= Rule: Vertical Parameter Alignment
:source-highlighter: highlight.js

Проверяет, что параметры функции, расположенные на нескольких строках, выровнены по вертикали.

*Identifier*: `vertical_parameter_alignment`

== Non-compliant

[source,swift]
----
func foo(param1: Int,
    param2: String) {}
----

== Compliant

[source,swift]
----
func foo(param1: Int,
         param2: String) {}
----
