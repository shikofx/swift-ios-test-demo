= xccov: Анализ покрытия кода
:source-highlighter: highlight.js

`xccov` — это стандартная утилита командной строки от Apple, которая входит в состав Xcode. Она предназначена для просмотра и анализа данных, содержащихся в бандлах `.xcresult`, которые генерируются во время сборки и тестирования проектов Xcode.

Основное применение `xccov` в нашем проекте — это извлечение информации о покрытии кода тестами.

== Основной рабочий процесс

Работа с `xccov` состоит из двух ключевых этапов:

1.  **Генерация `.xcresult`**: Запуск тестов с включенной опцией сбора данных о покрытии.
2.  **Анализ `.xcresult`**: Использование `xccov` для извлечения и представления данных в нужном формате (консоль, JSON, HTML).
2.  **Анализ `.xcresult`**: Использование `xccov` для извлечения данных в формате JSON для дальнейшей обработки.

=== Шаг 1: Генерация данных о покрытии

Чтобы `xccov` мог работать, ему нужен файл с результатами тестов. Для его создания выполните в терминале следующую команду из корневой директории проекта:

[source,bash]
----
xcodebuild test \
  -project "SDET Demo App.xcodeproj" \
  -scheme "SDET Demo App" \
  -destination 'platform=iOS Simulator,name=iPhone 15,OS=17.5' \
  -enableCodeCoverage YES \
  -resultBundlePath "TestResults.xcresult"
----

* `-enableCodeCoverage YES`: Ключевой флаг, который указывает `xcodebuild` собирать данные о покрытии.
* `-resultBundlePath "TestResults.xcresult"`: Указывает, куда сохранить бандл с результатами.

=== Шаг 2: Анализ данных с помощью xccov

После того как `TestResults.xcresult` создан, вы можете использовать `xccov` для его анализа.

IMPORTANT: Утилита `xccov` должна вызываться через `xcrun`, чтобы гарантировать использование правильной версии из активного набора инструментов Xcode.

. *Просмотр сводки в консоли:*
+
Для быстрого обзора покрытия по файлам и таргетам.
+
[source,bash]
----
xcrun xccov view --report TestResults.xcresult
----

. *Экспорт в JSON (используется в CI):*
+
Этот формат идеально подходит для дальнейшей программной обработки, например, для генерации кастомных отчетов, как это делаем мы в CI.
+
[source,bash]
----
xcrun xccov view --report TestResults.xcresult --json > coverage.json
----

. *Генерация HTML-отчета:*
+
Для детального визуального анализа. `xccov` создаст директорию (по умолчанию `index.html`), содержащую интерактивный отчет.
=== Шаг 3: Генерация кастомного HTML-отчета
+
+
`xccov` не предоставляет встроенной возможности для создания удобного HTML-отчета. Именно поэтому в нашем проекте используется кастомный Python-скрипт, который парсит `coverage.json` и генерирует интерактивный Markdown/HTML файл для сайта.
+
[source,bash]
----
xcrun xccov view --report --html TestResults.xcresult
python3 .github/actions/swift-coverage-report/swift_coverage.py \
  --json-path "coverage.json" \
  --source-dir "." \
  --output-path "coverage-report.md"
----

После выполнения откройте файл `index.html/index.html` в браузере, чтобы просмотреть отчет.
