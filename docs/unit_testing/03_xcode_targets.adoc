== Теория

=== Что такое таргет?

*Таргет (Target)* в Xcode — это инструкция по сборке одного продукта. Продукт может быть:

* Приложением для iOS, macOS, watchOS.
* Фреймворком или библиотекой.
* **Тестовым бандлом (Test Bundle)**.

Каждый таргет определяет, какие файлы исходного кода и ресурсы включать в сборку, а также содержит настройки сборки (build settings), такие как версия SDK, права (entitlements) и т.д. Один проект Xcode может содержать несколько таргетов.

=== Зачем нужен отдельный таргет для тестов?

Тесты компилируются в отдельный исполняемый пакет (бандл), который затем запускается и взаимодействует с кодом вашего основного приложения. Разделение на таргеты позволяет:

* **Изолировать тестовый код:** Код тестов не попадает в финальную сборку приложения, которую вы отправляете в App Store.
* **Иметь свои зависимости:** Тестовый таргет может иметь собственные зависимости (например, библиотеки для мокирования), которые не нужны основному приложению.
* **Управлять доступом:** С помощью ключевого слова `@testable import` тестовый таргет получает доступ к `internal` сущностям основного таргета, что упрощает тестирование.

=== Как создать тестовый таргет

Если вы не добавили тесты при создании проекта, их легко добавить позже.

. Откройте ваш проект в Xcode.
. Выберите `File` -> `New` -> `Target...`
. В появившемся окне в секции `Test` выберите `Unit Testing Bundle` и нажмите `Next`.
. Xcode предложит стандартные настройки. Обычно их можно оставить без изменений. Убедитесь, что в поле `Target to be Tested` выбрано ваше основное приложение.
. Нажмите `Finish`.

После этого в навигаторе проекта появится новая папка с названием вашего проекта и суффиксом `Tests`, содержащая шаблонный файл для ваших будущих тестов.
