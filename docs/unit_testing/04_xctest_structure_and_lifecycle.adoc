== Теория

=== Структура тестового класса

Тестовый класс в `XCTest` — это обычный класс Swift, который наследуется от `XCTestCase`.

[source,swift]
----
import XCTest
@testable import MyAwesomeApp // Импортируем основной таргет для доступа к его коду

class CalculatorTests: XCTestCase {

    // 1. Свойства (объекты для тестирования)
    var sut: Calculator! // sut = System Under Test (тестируемая система)

    // 2. Методы жизненного цикла
    override func setUp() {
        super.setUp()
        // Код здесь выполняется ПЕРЕД каждым тестовым методом
        sut = Calculator()
    }

    override func tearDown() {
        // Код здесь выполняется ПОСЛЕ каждого тестового метода
        sut = nil
        super.tearDown()
    }

    // 3. Тестовые методы
    func testAddition() {
        // ... код теста ...
    }

    func testSubtraction() {
        // ... код теста ...
    }
}
----

*Имена тестовых методов должны начинаться со слова `test`*, иначе Xcode не распознает их как тесты.

=== Жизненный цикл теста

Для каждого тестового метода (`test...()`) Xcode выполняет следующую последовательность:

. `setUp()` — подготовка окружения. Здесь создаются экземпляры классов, сбрасываются состояния.
. `test...()` — выполнение самого теста.
. `tearDown()` — очистка. Здесь освобождаются ресурсы, обнуляются свойства.

Такой цикл гарантирует, что каждый тест запускается в чистом, предсказуемом состоянии и не влияет на другие тесты.

=== Паттерн Given-When-Then

Это простой и эффективный способ структурировать тело тестового метода, делая его более читаемым.

* *Given (Дано):* Секция, где вы настраиваете начальное состояние. Создаете объекты, задаете входные данные.
* *When (Когда):* Секция, где вы выполняете тестируемое действие. Вызываете метод, который хотите проверить.
* *Then (Тогда):* Секция, где вы проверяете результат. Используете `XCTAssert`, чтобы убедиться, что результат соответствует ожиданиям.

[source,swift]
----
func testAddition() {
    // Given
    let number1 = 5
    let number2 = 10
    let expectedResult = 15

    // When
    let actualResult = sut.add(number1, number2)

    // Then
    XCTAssertEqual(actualResult, expectedResult, "Сумма 5 и 10 должна быть 15")
}
----
